# ☕ Starbucks Dashboard | Power BI

## 📌 Project Overview

This project is an interactive Starbucks Dashboard developed using Microsoft Power BI. It provides insights into Starbucks beverages, their categories, and nutritional information through interactive visualizations and KPI cards.

## 🎯 Project Objectives

- Analyze Starbucks beverage data.
- Compare nutritional values across beverage categories.
- Identify patterns in calories, sugar, and caffeine content.
- Present insights through interactive visualizations.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard creation and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculations and measures.

## 📊 Dashboard Highlights

The dashboard includes:

- **Total Beverages:** Overview of the total number of beverages.
- **Average Sugar:** Displays the average sugar content.
- **Average Calories:** Shows the average calorie content.
- **Average Caffeine:** Highlights the average caffeine content.
- **Beverage Category Analysis:** Breakdown of beverages by category.
- **Caffeine Comparison:** Compares average caffeine across beverage categories.
- **Interactive Filters:** Filter data using protein content and beverage preparation type.
- **Geographical Analysis:** Country-wise visualization.
